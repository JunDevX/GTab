## О проекте

**GTab** — расширение для браузера, которое заменяет стандартную страницу новой вкладки на кастомную: тёмную, минималистичную, с акцентом на системный цвет Windows.

Вместо дефолтной пустой страницы браузера вы получаете аккуратную тёмную тему, круглую поисковую строку по центру и акцентную кнопку справа — в духе Android 16 / 17.

Всё настраивается: тема, акцентный цвет и поисковая система. Настройки открываются прямо из списка расширений — один клик, и вы в панели управления.

## Возможности

### Тёмная тема с системным акцентом
Базовая тема — тёмная. Акцентный цвет по умолчанию подхватывается из системы (Windows accent color), поэтому интерфейс выглядит «своим» на любом ПК. Цвет можно сменить вручную.

### Круглая поисковая строка
По центру экрана — поисковая строка со скруглением, справа от неё акцентная кнопка в стиле Android 16 / 17. Ввод — Enter или кнопка.

### Выбор поисковой системы
- **Google**
- **Yandex**
- **DuckDuckGo**

Каждой системе соответствует своя анимация запуска — вкладка не просто «открывается», а представляется.

### Панель настроек
Открывается по клику на иконку расширения в списке расширений:
- выбор темы;
- выбор акцентного цвета;
- выбор поисковой системы.

## Анимации запуска

| Поисковик | Что происходит |
|---|---|
| **Google** | Из центра появляется серая точка, быстро переливается цветами логотипа Google, превращается в букву **G**, которая раскрывается в слово **Google**. |
| **Yandex** | Буквы слова **Yandex** плавно поднимаются одна за другой. |
| **DuckDuckGo** | Появляется уточка, плывёт вправо, а за ней проявляется надпись **DuckDuckGo**. |

Анимации короткие, не блокируют ввод и проигрываются один раз при открытии новой вкладки.

## Умный поиск: ключевые слова

Поисковая строка распознаёт служебные запросы и открывает нужный сервис напрямую вместо страницы результатов.

### Google

| Ввести в строку | Откроется |
|---|---|
| `Гемини`, `Gemini`, `гугл ии`, `google ai` | `gemini.google.com` |
| `email`, `почта`, `гугл почта`, `gmail` | `gmail.com` |

### Yandex

| Ввести в строку | Откроется |
|---|---|
| `ии`, `яндекс ии`, `yandex ai` | страница Яндекс ИИ |
| `email`, `яндекс почта`, `почта`, `yandex mail` | `mail.yandex.ru` |

Всё, что не совпало с ключевым словом, уходит в обычный поиск выбранной системы.

## Как это выглядит в работе

1. Открываете новую вкладку — вместо стандартной страницы появляется тёмный экран GTab.
2. Проигрывается анимация выбранного поисковика.
3. Пишете запрос — GTab либо ищет, либо, если запрос служебный, сразу открывает нужный сервис.
4. Клик по иконке расширения — панель настроек, где можно сменить тему, акцент и поисковик.

## Стек и принципы

- Расширение для Chromium-браузеров (Chrome, Edge, Brave, Vivaldi и др.).
- Переопределение страницы новой вкладки средствами браузерного API.
- Чистый интерфейс без внешних зависимостей — быстрая загрузка, никакой лишней сети.
- Все настройки хранятся локально, в браузере. Никакой телеметрии.

## Установка (для разработки)

1. Скачайте или склонируйте репозиторий.
2. Откройте страницу управления расширениями браузера (`chrome://extensions` или `edge://extensions`).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и укажите папку проекта.
